# Civic Mirror - Frontend 🌐

The frontend client for Civic Mirror built with React 19, Vite, and TailwindCSS.

* **Live Demo:** [https://civicmirror.onrender.com](https://civicmirror.onrender.com)
* **Backend API:** [https://civic-mirror-backend.onrender.com](https://civic-mirror-backend.onrender.com)

## Quick Start

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```

## Environment Variables

| Variable | Description | Default |
| :--- | :--- | :--- |
| `VITE_BACKEND_URL` | Base URL of the backend API service | `http://localhost:3001` |
